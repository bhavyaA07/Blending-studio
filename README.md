# NCMRWF Unified Meteorological Blending Studio

An interactive studio for exploring blended meteorological forecasts, model weighting, and severe weather hazards.

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies with `npm install`.
2. Copy `.env.example` to `.env` and set `GEMINI_API_KEY` to enable live Gemini analysis.
3. Start the app with `npm run dev`.
